# Cross-Language Conformance and Interop Plan

**Goal:** prove the spec across implementations, not just within one: a language-neutral vector runner, adversarial vectors that pin the ambiguous edges, and TS↔Python interop for real manifests and signals.

**Architecture:** A root `conformance/` orchestrator runs a thin harness inside each SDK over `test-vectors/` and a new frozen `test-vectors/v2/`. Each harness prints a JSON summary and exits non-zero on any mismatch. A separate interop flow has each SDK sign a fixed manifest and signal, then verify the other's output byte-for-byte. The v2 vectors are generated by a corrected reference implementation and remain the contract.

**Tech Stack:** Node 24 + built `sdk/typescript/dist`, Python 3.12 + `sdk/python/ccp`, stdlib only for the runners. No new dependencies.

**Spec:** `CCP_Working_Draft_v0.5.md` §10.3, §25.1–25.2, §26.1, §26.3.

## Global Constraints

- `test-vectors/*.json` (v1) is frozen. Do not edit it; v2 is a new directory.
- Both SDKs must pass v1 and v2; the 51 v1 vectors stay green.
- `src/`/`ccp/` gain no Node- or platform-specific imports.
- The conformance runner is the source of truth for v2; SDK tests are convenience.
- Every newly found ambiguity is either fixed in the spec or explicitly pinned by a vector.
- Commit only when the user asks.

## Findings this phase must resolve

The spec already says: `-0` is rejected, keys that differ only by normalization are duplicates, key sort uses code points, strings must be valid UTF-8/NFC, and `signature`-last applies only at the top level. The implementations disagree on several of these:

| Finding | TS | Python | Resolution |
| --- | --- | --- | --- |
| `-0` | rejects (`negative`) | accepts as `0` | Python rejects in `parse_int` |
| NFC key collision | emits duplicate keys | emits duplicate keys | both reject (`duplicate`) |
| Unpaired surrogate escape | throws `RangeError`, no code | accepts, then `UnicodeEncodeError` on sign | both reject (`malformed`) |
| Nested `signature` | forced last at every level | forced last at every level | only top level appends last |
| `__proto__` key | prototype mutation | safe dict | parse into `Object.create(null)` |
| Clock equality | `>=` (correct) | `>=` (correct) | pin with v2 vectors; fix the v1-style reference logic in the v2 generator |
| Limits equality | `counter + 1 > limit` (correct) | same | pin both sides of the boundary |

## Harness contract

`run.<ext> <vectors-dir>` reads whichever of `canonical-json.json` and `validation.json` exist under the directory, prints:

```json
{
  "canonical-json": {"passed": 20, "failed": 0, "failures": []},
  "validation": {"passed": 18, "failed": 0, "failures": []}
}
```

and exits 0 iff every case passed. A failure entry is `{"id", "expected", "got"}`.

Validation vectors pass `grant`, `signal`, `signer`, and `context` to the same decision entry point the SDK tests use, with the fixed intent spec and params schema from the v1 fixture.

## Interop contract

`interop.<ext> generate <out.json>` writes:

```json
{
  "manifest_wire": "…",
  "manifest_digest": "sha256:…",
  "signal_wire": "…",
  "signal_signing_sha256": "…"
}
```

`interop.<ext> verify <in.json>` verifies the manifest and signal with the fixed public keys, recomputes the digest and signing hash, and exits non-zero on any mismatch. Ed25519 is deterministic, so both generators must produce byte-identical wires; `conformance/interop.py` compares them.

### Task 1: Frozen v2 vectors

**Files:** create `test-vectors/v2/{generate.py,README.md}` and the two JSON files.

Canonical cases (`cj2-*`):

1. astral-plane key sort: `a` < `U+FFFF` < `U+1F600` (UTF-16 sort would fail);
2. NFD key normalizes to NFC in output;
3. NFD value normalizes to NFC in output;
4. two distinct keys collapse under NFC → `duplicate`;
5. `{"a":1,"\u0061":2}` → `duplicate`;
6. `-0` → `negative`;
7. `-0.0` → `negative`;
8. lone high surrogate escape → `malformed`;
9. lone low surrogate escape → `malformed`;
10. high surrogate followed by a non-low code → `malformed`;
11. valid surrogate pair → literal astral character;
12. nested `signature` is sorted normally (not last);
13. top-level `signature` is last;
14. `__proto__` is an ordinary key and survives round-trip;
15. `18446744073709551616` round-trips exactly;
16. `1e3` → `float`;
17. `\u001F` emits lowercase `\u001f`;
18. escaped quote/backslash/solidus: solidus becomes literal;
19. U+007F stays literal;
20. a leading BOM → `malformed`.

Validation cases (`v2-*`):

- `now == grant.expires_at` → `grant_expired`;
- `now == signal.expires_at` → `request_expired`;
- one second before both → authorized;
- `counters == limit - 1` → authorized; `== limit` and `> limit` → `limit_exceeded`;
- seen request AND expired request → `request_expired` (expiry precedes replay);
- revoked/paused/suspended with an expired timestamp → explicit lifecycle code wins;
- `state == "expired"` with a future timestamp → `grant_expired`;
- missing capability AND `per_action` → `capability_unavailable` (step 10 before 11);
- intent not allowed AND revoked → `grant_revoked` (step 5 before 6);
- invalid params AND expired request → `invalid_request` (step 7 before 8);
- two limits, one at the boundary → `limit_exceeded`;
- empty limits → authorized.
